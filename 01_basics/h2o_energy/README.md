# CP2K Practice

This repository contains my practice and learning exercises with **CP2K**, focusing on computational chemistry, electronic structure calculations, and computational workflow development.

## Current Exercises

### H₂O Potential Energy Exploration

- Performed CP2K energy calculations for H₂O with fixed molecular geometries
- Explored how changing an O–H bond distance affects the molecular energy
- Conducted an energy scan over a range of O–H bond distances
- Generated and modified CP2K input files for different molecular geometries
- Used **Python** to automate modification of CP2K input files
- Processed CP2K output files to obtain calculated energies
- Visualized the relationship between O–H bond distance and molecular energy using **Matplotlib**
- Practiced organizing computational inputs, outputs, scripts, and generated results into a reproducible workflow

## Tools

- **CP2K** — electronic structure calculations
- **Python** — input-file manipulation, automation, and data analysis
- **Matplotlib** — visualization of calculated energy data
- **Git / GitHub** — version control, project organization, and documentation
